# Numpad Hackpad

A custom numpad style macropad, built for the NASA x Hack Club Stardance Challenge.

## About

This is my first hardware project. I plan it to be a fully custom mechanical keypad designed and built from scratch, styled like a numpad. It will be a Stardance hardware submission and a personal build I'm using to learn PCB design and firmware.

## Status

Just started.

## Folder structure

- `pcb/` — KiCad files
- `cad/` — Case design files
- `firmware/` — Code for the board
- `assets/` — Photos, renders, wiring diagrams
- `production/` — Stuff for building the thing and ordering parts.
