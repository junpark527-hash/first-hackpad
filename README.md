# Numpad Hackpad

A custom numpad style macropad, built for the NASA x Hack Club Stardance Challenge.

## About

This is my first hardware project. I plan it to be a fully custom mechanical keypad designed and built from scratch, styled like a numpad. It's both a Stardance hardware submission and a personal build I'm using to learn PCB design and firmware.

## Status

Just started.

## Folder structure

- `pcb/` — KiCad project files, schematics, gerbers, BOM
- `cad/` — Case/enclosure design exports (STEP, STL, F3D)
- `firmware/` — Microcontroller code
- `assets/` — Photos, renders, wiring diagrams
- `production/` — Files related to fabrication/assembly
